# 🧹 Office Uninstaller & Cleaner Script (`justdeleteOffice.py`)

سكربت بلغة **Python** مخصص لنظام التشغيل Windows يهدف إلى **إزالة وحذف جميع إصدارات برامج Microsoft Office** المتبقية أو المستعصية بشكل كامل وشامل، مع إجراء فحص تلقائي (Verification) لتأكيد خلو النظام من أي بقايا.

---

## ✨ المميزات الرئيسية

* **إيقاف العمليات والخدمات:** إنهاء كافة العمليات النشطة لـ Office بالذاكرة (مثل Word, Excel, ClickToRun) وإزالة خدمات النظام المرتبطة بها.
* **التنظيف الميداني الحقيقي:** حذف جميع مجلدات التثبيت من `Program Files` و`ProgramData` ومجلدات التطبيقات لـ `AppData`.
* **تنظيف سجل النظام (Registry):** إزالة المفاتيح والمدخلات التابعة لـ Office لمنع حدوث تعارض عند إعادة التثبيت (مثل التعارض بين 32-bit و 64-bit).
* **الفحص والتحقق التلقائي (Verification):** إعادة فحص السجل والقرص فور الانتهاء لتقديم تقرير شامل يؤكد نجاح الإزالة.

---

## 📋 المتطلبات

1. **نظام التشغيل:** Windows 10 / 11 (أو إصدارات Windows Server).
2. **بيئة التشغيل:** Python 3.x مثبتة على الجهاز.
3. **الصلاحيات:** صلاحيات المسؤول (**Administrator**).

---

## 🛠️ آلية عمل السكربت (مراحل التنفيذ)

يمر السكربت بـ 5 مراحل متتالية لضمان الحذف الشامل:

| المرحلة | الوصف |
| :--- | :--- |
| **1. التحقق من الصلاحيات** | التأكد من أن السكربت يعمل بصلاحيات المسؤول عبر `ctypes.windll.shell32.IsUserAnAdmin()`. |
| **2. إيقاف الخدمات والعمليات** | استخدام أمر `taskkill` لإنهاء العمليات (مثل `WINWORD.EXE`, `OfficeClickToRun.exe`) وأمر `sc delete` لحذف خدمة `ClickToRunSvc`. |
| **3. حذف المجلدات** | فحص المسارات الشائعة على القرص وحذف المجلدات باستخدام `shutil.rmtree`. |
| **4. تنظيف Registry** | حذف المفاتيح الرئيسية المسؤولة عن تشغيل وتثبيت Office باستخدام أمر `reg delete`. |
| **5. الفحص النهائي (Verification)** | قراءة قيم Registry والمسارات مجدداً عبر وحدة `winreg` لتأكيد ناتج التنظيف وتنبيه المستخدم بالنتيجة. |
